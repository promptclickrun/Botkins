# Botkins navigation icons
Use the six 24 × 24 SVGs in sidebar order: Home, Today, Chats, Work, Projects, Wiki. The 1.75-unit rounded strokes inherit currentColor when inlined. For external image elements, use the asset as a CSS mask or set the color in the SVG itself.

Center a 24 px icon in a 48 px button. Give the current destination a persistent rounded background and aria-current="page". Give each icon-only link its destination as aria-label, hide its decorative SVG from assistive technology, and show the same label on hover and keyboard focus. Keep a visible keyboard focus ring.
