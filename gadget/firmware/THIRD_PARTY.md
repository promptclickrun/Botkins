| Path | Origin | Licence | What changed |

| `esp32/boards/m5stack-stopwatch/stopwatch_power.hpp`, `stopwatch_power.cpp` | Hermes Gadget SDK: `firmware/drivers/stopwatch.hpp`, `firmware/drivers/stopwatch.cpp` (`StopWatchControl::begin`, `set_amplifier`, the register constants) and `firmware/esp32/main/port_stopwatch.cpp` (`StopWatchBoard::begin`: the I2C devices at 100 kHz) | MIT, Copyright (c) 2026 Hermes Gadget SDK contributors ([`LICENSES/HermesGadget-MIT.txt`](LICENSES/HermesGadget-MIT.txt)) | The M5PM1/M5IOE1 register sequence, values and delays are unchanged. Merged into one class that talks to the I2C devices itself (no `std::function` indirection). Left out: battery reading, the red key, power-off, the CST820 touch "stay awake" write, battery curves. |
| `esp32/boards/m5stack-stopwatch/audio.hpp`, `audio.cpp` | Hermes Gadget SDK: `firmware/esp32/main/port_codec.cpp` (`CodecAudio::begin`, the `CodecMic` and `CodecSpeaker` tasks) | MIT, as above | Only the StopWatch's case (one ES8311 for both directions, its settings unchanged: I2S1 master, Philips 16-bit mono, MCLK = 256 fs, `use_mclk`, amplifier supply 3.3 V, mic gain 24 dB, amplifier through the M5IOE1, 20 ms settle before unmute and before amplifier off, silence pushed through the DMA ring before muting). Changed: 16 kHz for both directions (theirs 24 kHz), volume 60 (theirs 70), a 2-second queue, `write` blocks until queued and `end` waits until played, as the Botkins core's `Speaker` asks. Their PA queue, power-down and underrun statistics are left out. |
| `esp32/boards/m5stack-stopwatch/font5x7.hpp`, `font5x7.cpp` | Hermes Gadget SDK: `firmware/core/src/font5x7.cpp` (the `kGlyphs` and `kLatin1` tables), `firmware/core/include/hg/font.hpp` | MIT, as above | Glyph tables copied unchanged (generated by script from their file). Cyrillic, CJK and the text helpers left out; a small `glyph()` lookup. |
| `esp32/main/console.cpp` (the interrupt clean-up in `install()`) | Hermes Gadget SDK: `firmware/esp32/main/port_console.cpp` | MIT, as above | The USB-Serial-JTAG interrupt-enable clean-up before the driver is installed (a fix found on this board). The rest of the file is Botkins'. |
| `esp32/boards/m5stack-stopwatch/display.cpp` (`kInit`, the CO5300 start-up commands) | Waveshare board support package `waveshare/esp32_s3_touch_amoled_1_75` 2.0.6 (github.com/waveshareteam/Waveshare-ESP32-components, commit `e81486c57b63352692382053496ee24a9ab74574`, `bsp/esp32_s3_touch_amoled_1_75/esp32_s3_touch_amoled_1_75.c`, `lcd_init_cmds`) | Apache-2.0 ([`LICENSES/Apache-2.0.txt`](LICENSES/Apache-2.0.txt)); the source file carries no copyright line of its own | The 14 commands copied unchanged as register values. | `core/third_party/monocypher/` | Monocypher (already in the core before this port) | CC0-1.0 or BSD-2-Clause (`core/third_party/monocypher/LICENCE.md`) | Unchanged; built as C99. |

Hardware facts used without copying code: the StopWatch's pin map (I2C 47/48, keys 1 and 2, QSPI panel 39/40/41/42/46/45, I2S 18/17/15/21/16), the panel's 6-column gap and 40 MHz clock, and the flash/PSRAM/console/TCP settings in `esp32/boards/m5stack-stopwatch/sdkconfig.defaults`, all as the Hermes Gadget firmware has them for `m5stack-stopwatch` (`firmware/esp32/main/board.cpp`, `firmware/esp32/boards/m5stack-stopwatch/sdkconfig.defaults`, `firmware/esp32/sdkconfig.m5stack-stopwatch`; MIT). The Hermes firmware's own notices name M5Stack's StopWatch documentation, schematic and M5PM1/M5IOE1 libraries (MIT) as the source of those facts.

The Wi-Fi carry-over (`esp32/main/nvs_storage.cpp`, `earlier_wifi`) reads the keys the Hermes firmware writes (`hgadget` / `wifi_ssid`, `wifi_pass`, `wifi_nets`); no code is copied.

## Not copied

From the Hermes reference, deliberately: `panel_sh8601.hpp`, `crowpanel_st7701_init.hpp` and anything Elecrow, `blake2s.c`, the CJK font data, mascot art, the "Hermes" names and branding, and nothing from `port_amoled.cpp` or `port_dsi.cpp` (the CO5300 values come from Waveshare's Apache-2.0 file directly, above).
